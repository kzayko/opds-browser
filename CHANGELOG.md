# История изменений

**GitHub**: https://github.com/kzayko/opds-browser

## [1.0.0] - 2024-01-XX

### Добавлено
- ✅ Графический интерфейс для просмотра OPDS каталогов
- ✅ Навигация по папкам и книгам с иконками
- ✅ Поиск книг по названию и автору
- ✅ Отображение деталей книг (название, автор, описание, обложка)
- ✅ Сохранение и восстановление последней позиции
- ✅ Управление каталогами через GUI
- ✅ Кнопки навигации (Back, Up, Home, Next/Previous)
- ✅ Поддержка CLI аргументов для указания каталога
- ✅ Автоматическое сохранение конфигурации в JSON
- ✅ Поддержка вложений (ссылки на скачивание)
- ✅ Документация в формате Markdown
- ✅ Управление логированием через конфигурацию и переменные окружения
- ✅ Поддержка загрузки переменных из .env файлов
- ✅ Настройка прокси через переменные окружения
- ✅ Настройка таймаутов и User-Agent
- ✅ Указание каталога по умолчанию через переменные окружения
